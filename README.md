# 🚖 Executive Overview of Bangladeshi Ride-Sharing Platforms

![Dashboard Preview](Interactive%20Dashboard%20Bangladesh.jpg)

This Power BI report explores the operational and financial performance of major ride-sharing platforms in Bangladesh—Uber, Pathao, inDrive, and OBHAI[cite: 1, 3]. I built this project to practice data modeling with DAX and turn raw mobility records into a clean, interactive view for comparing market share and regional revenue[cite: 1, 3].

## 📊 What is inside the dashboard
- 📈 **Core Metrics:** Tracks 8K completed bookings, 2M in completed ride revenue, an average fare of 210.69, 1K cancellations (0.13 cancellation rate), 61.61K KM in estimated distance, and 327.67K in platform commissions[cite: 1, 3].
- 🏆 **Platform Comparison:** Breaks down booking share across Pathao (37.28%), Uber (34.36%), inDrive (20.71%), and OBHAI (7.65%), alongside each platform's share of total cancellations[cite: 1, 3].
- 🏙️ **City and Payment Splits:** Shows revenue distribution by city—with Dhaka leading at 56.42% and Chattogram at 18.47%—and compares revenue across Cash, bKash, Card, and Nagad[cite: 1, 3].
- 🏍️ **Vehicle Types:** Compares completed bookings across Bikes, Cars, and CNGs for each operator[cite: 1, 3].
- 🎛️ **Interactive Slicers:** Includes dropdown filters at the top right so users can filter the entire report by specific Platform or City[cite: 1, 3].

## 🛠️ Tools Used
- 📊 **Power BI Desktop** for report layout and visual design
- 🔄 **Power Query** for cleaning and shaping the raw dataset
- 🧮 **DAX** for custom measures including cancellation rate, average fare, and dynamic percentage shares[cite: 1, 3]
